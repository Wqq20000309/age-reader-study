# Clinician Blinded Apparent-Age Evaluation Workbench

Lightweight web evaluation workbench (`index.html` ~13 KB + separate CC BY 4.0 portraits in `imgs/`).
All displayed portraits originate exclusively from public CC BY 4.0 research datasets:
- Face Research Lab London Set (DeBruine & Jones, 2021; CC BY 4.0)
- FairFace Validation Dataset (Kärkkäinen & Joo, 2021; CC BY 4.0)

No patient data, ground-truth ages, or study condition labels are included.
